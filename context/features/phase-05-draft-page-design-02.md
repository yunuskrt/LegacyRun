# Phase 5 - Draft Page Design (Part 2)

## Overview

This is phase 2 of 2 for the draft page UI layout. Use the screenshot referenced below for how it should look. If needed use mock data. Just implement the UI.

## Requirements for part 2

- Motion animations transitions in necessary places (eg. placing the selected draft player)
- Theme usage
- Enabled/disabled states of draft players
- Enabled/disabled states of buttons
- Court player positions must remain fixed and correctly aligned with the court across all screen sizes and responsive breakpoints
